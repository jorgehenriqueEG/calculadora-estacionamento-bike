# Calculadora Estacionamento Bike
## Descrição do Problema
Um sistema para calcular o valor de estacionamento de bicicletas em eventos esportivos. A taxa base é R$ 5,00 por hora, mas se a bicicleta for de competição (tipo 'pro'), ganha 50% de desconto.
## Requisitos
* Receber o tempo em horas e o tipo da bike.
* Aplicar desconto apenas para bikes 'pro'.
* Exibir o valor final formatado.
## Exemplo de Uso
Entrada: 3 horas, tipo 'road'
Saída: Valor a pagar: R$ 15.00
